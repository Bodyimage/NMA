# Body Image Living Review static site

Upload these files and folders to the same GitHub Pages directory:

- `index.html`
- `references.html`
- `assets/`
- `data/`

The homepage links to `references.html`. The reference page loads data from `data/references.js`, so future updates only require replacing that data file if the page structure is unchanged.


Updated reference data from livingmeta.xlsx: 119 references parsed. Update `data/references.js` to refresh the website reference list.
